▸ Formula notes

1 · Player damage per hit

dL = EnemyLevel - 100
D(L) = 321 + 4.353*dL + 0.0108*dL^2

Piecewise Calibrations:
• If Level > 100:  D(L) += 0.024 * dL
  (Calibrates Level 150 defense to 566.85 so 310-damage thresholds resolve exactly,
   while preserving verified endgame targets such as Ilgin at 942/933)
• If Level < 100:  D(L) += 4.0 * (1 - Level / 100)
  (Smooths early bestiary damage scaling, including a +0.5 threshold correction
   at Levels 9–11 to match Level 10 Deer at 457 damage)
• Clamp: D(L) = max(0, D(L))
  (Allows Level 1 unarmored mobs like Rabbit to drop to 0 defense)

baseHit    = ( 0.665318 * AP^2 ) / ( AP + D(L) )
withCrit   = baseHit + ( CritChance * CritDamage / 100 )
withSlayer = withCrit * ( 1 + SlayerRank% / 100 )
damage     = max( 1, round( withSlayer ) + FlatDamage )

Verified across raw combat logs (AP 240–1650+). Accurate across all bestiary levels (1–150).

2 · Hit chance and enemy power

enemyPower = floor( 1.974 * Level + Level^2 / 208 )
playerHitChance = ( Accuracy / ( Accuracy + enemyPower ) ) * 100
enemyHitChance  = max( 10, ( enemyPower / ( enemyPower + Agility ) ) * 100 )

Standard Hill/Michaelis-Menten curve. Enemy hit chance has a hard floor at 10.00% (reached when Agility >= 9 * enemyPower).

3 · Enemy damage per hit

dL = EnemyLevel - 100
K(L) = 505.035 + 6.502*dL + 0.01628*dL^2

Curvature Adjustment:
• If 15 < Level < 100:  K(L) -= ((100 - Level) * (Level - 15)) / 650
  (Corrects upward quadratic flare across mid-levels 70–76 to match in-game 70/74/78/82,
   while leaving base stats at low levels 8–14 intact)

enemyDamage = max( 1, floor( (0.66173 * K(L)^2) / (K(L) + Protection) ) )

Mitigated incoming damage uses standard game engine integer flooring, clamped to a minimum of 1 damage per landed hit.

4 · Enemy HP scaling and hits to defeat

Universal 3-Step Scaling Engine:

1. Normalize:  u = (Level - minLevel) / (maxLevel - minLevel)
2. Curve:      adjusted = u^curve   (curve = 1.0 for linear HP)
3. Scale:      HP = floor( minHP + (maxHP - minHP) * adjusted )

Bracket 1 — Overworld Mobs (Levels 1 to 99):

minLevel = 1, maxLevel = 100, minHP = 23 (Rabbit), maxHP = 830 (Standard)
HP(L) = floor( 23 + 807 * (Level - 1) / 99 )

Bracket 2 — Endgame Scaling Slider (Levels 100 to 150):

minLevel = 100, maxLevel = 150
HP(L) = floor( HP100 + (HP150 - HP100) * (Level - 100) / 50 )

Standard Mob / Wisp   830  -> 1250  (+8.40 / lvl)
Kikimora              871  -> 1316  (+8.89 / lvl)
Man Moth              899  -> 1353  (+9.07 / lvl)
Banshee               929  -> 1398  (+9.38 / lvl)
Arvendor Guardian     954  -> 1426  (+9.43 / lvl)

Expected Turn Damage & Defeat Threshold:

expectedTurnDamage = max( 0.01, (damage * hitChance) / 100 )
hits = ceil( enemyHP / expectedTurnDamage )

Evaluates expected damage continuously across hits to prevent premature integer truncation from creating off-by-one hit count traps.
